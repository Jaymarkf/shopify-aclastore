# Large group preview

The unpublished **Horizon - large catalog preview** theme can repeat the 160 real OLO products into a 1,120-row simulation. It does not create sample products or modify inventory. Sample cart submission is disabled.

Preview: https://c5p0rn-q5.myshopify.com/products/olo-premium-markers-brush?preview_theme_id=167230242886

Append `&catalog_test=off` to compare the actual 160 products. Published and local production templates have simulation disabled.

Assignments now come from **OLO Brush colors**, a native collection. The old JSON catalog and multipart fields have been retired. The compact metadata index is generated by Liquid from current collection products, in native pages of 250. Detail pages hold 20 current products; viewport virtualization bounds rendered rows while preserving selection and focused controls.

This supports thousands of assignments without rendering thousands of interactive rows. It is not a promise of unlimited Shopify capacity: native collection/pagination and request limits still apply. The manager's workflow stays the same as group size grows.

See [the simple manager guide](product-manager-product-groups.md).
