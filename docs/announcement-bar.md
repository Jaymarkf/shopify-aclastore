# Edit the announcement bar

Open **Online Store → Themes → Customize (Edit theme) → Header → Announcement bar**.

## Bar settings

- **Announcement style**: Scrolling marquee, Fading slideshow, or Static messages.
- **Marquee speed**: Pixels per second; higher is faster. Start around 40.
- **Marquee direction**: Scroll left or scroll right.
- **Pause on hover**: Stop while a visitor's pointer is over the bar.
- **Gap between messages**: Separate desktop and mobile spacing controls.
- **Section width**: Page container or full width.
- **Background color / Text color**: Choose the bar colors. Leave text color blank
  to let the theme choose a contrasting text color.
- **Divider thickness / Divider color**: Set the bottom border.
- **Padding**: Set top, bottom, start, and end spacing. Start is left in English.

## Messages, links, and fonts

1. Expand **Announcement bar** in the left sidebar.
2. Select an **Announcement** block, or choose **Add block → Announcement**.
3. Edit its text and optional link.
4. Set font, size, mobile size, line height, weight, letter spacing, capitalization,
   and optional individual text color. Use the text editor for bold or italic words.
5. Drag blocks to reorder the messages, then **Save**.

The marquee repeats your existing messages automatically to fill the bar. You only
need one block for each unique message. Do not add duplicate blocks to make it loop.

Visitors can pause/play the moving messages. Keyboard focus also pauses movement.
People who request reduced motion see stationary messages that wrap to fit; all
messages and links also remain available if JavaScript is unavailable.

The existing header artwork, navigation, hero, and product sliders are independent.
