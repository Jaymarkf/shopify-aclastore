# Homepage slideshow and category tiles

## Slider widths

The homepage hero slideshow uses **Full width**. Its banner spans the screen.

Only the **Featured products** carousel is contained inside the page margins. In the theme editor, open Featured products and keep **Width: Page** and **Keep carousel inside page container: on**. Other carousels retain their existing settings.

## Add category images

1. Open Home page in the theme editor.
2. Select **Category tiles**, already placed below the slideshow. Drag the section to any preferred position.
3. Open a **Category tile**, select its **Image**, and set its **Link**.
4. Use Add block ? Category tile to add another. Drag tiles to reorder them, or remove a block to remove a tile.
5. Save.

Each tile has only Image and Link settings. The whole image is clickable. Collection links automatically use the collection title as a fallback accessible label; the image's own library alt text takes priority.

## Add slides inside one tile

1. Open **Category tiles**, then expand the **Category tile** you want to edit.
2. Its existing **Image** and **Link** remain the first slide. You can leave them empty and use only nested slides instead.
3. Inside that tile, choose **Add block > Image slide**.
4. Select the slide's **Image** and **Link**. Repeat for more slides, and drag the Image slide blocks to reorder them.
5. Preview the tile immediately. With two or more configured images, it shows left/right arrows and supports touch swiping. One image remains a normal tile. Choose **Save** when you want to publish your edits.

The preview updates immediately as you add, remove, or change Image slides, before you save. Saving publishes your edits; it is not needed to activate the preview. Empty slide placeholders do not count toward the carousel arrows. A tile with one configured image has no arrows.

Blank slides are hidden from customers. Images load lazily at responsive sizes, using the theme's existing slideshow without an additional carousel library.

There is no custom slide cap. Shopify allows 50 dynamic blocks per section, counting the Category tile blocks and their nested Image slides together. Add another Category tiles section if you reach that platform limit.

Empty tiles are hidden from customers, so the homepage does not display sample graphics or blank cards while you prepare your images. The editor provides image placeholders.

In the section settings you can choose desktop/mobile column counts, landscape or square images, spacing and corner radius. For landscape cards, a 3:2 image (for example 900 x 600) fits the default shape. Below-fold images load lazily at responsive sizes. The tile uses the theme's native slideshow with a small listener for live editor changes; no app or external carousel library is required.

The **Category tile** block can also be added inside custom sections or groups that accept theme blocks, so you can place individual tiles in your own homepage layout.
