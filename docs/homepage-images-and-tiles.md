# Homepage slideshow and category tiles

## Slider widths

The homepage hero slideshow uses **Full width**. Its banner spans the screen.

Only the **Featured products** carousel is contained inside the page margins. In the theme editor, open Featured products and keep **Width: Page** and **Keep carousel inside page container: on**. Other carousels retain their existing settings.

## Add category images

1. Open Home page in the theme editor.
2. Select **Category tiles**, already placed below the slideshow. Drag the section to any preferred position.
3. Open a **Category tile**, select its **Image**, and set its **Link**.
4. Use Add block ? Category tile to add another. Drag tiles to reorder them, or remove a block to remove a tile.
5. Save.

Each tile has only Image and Link settings. The whole image is clickable. Collection links automatically use the collection title as a fallback accessible label; the image's own library alt text takes priority.

Empty tiles are hidden from customers, so the homepage does not display sample graphics or blank cards while you prepare your images. The editor provides image placeholders.

In the section settings you can choose desktop/mobile column counts, landscape or square images, spacing and corner radius. For landscape cards, a 3:2 image (for example 900?600) fits the default shape. Below-fold images load lazily at responsive sizes; no new JavaScript or app is required.

The **Category tile** block can also be added inside custom sections or groups that accept theme blocks, so you can place individual tiles in your own homepage layout.
