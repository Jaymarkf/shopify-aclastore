# Change the header background

1. Open **Online Store → Themes → Customize** (or **Edit theme**).
2. Select **Header**, then find **Colors**.
3. Keep **Show header background image** turned on.
4. Under **Background image**, select or upload your own image.
5. Adjust **Background image strength** if needed, then **Save**.

With no replacement selected, the header uses the included watercolor. Turn off
**Show header background image** to return to the normal header background color.
The image is decorative and does not change the header's height. It fills the
header and may crop at different screen sizes; keep any essential artwork away
from the edges. The shared image spans the header group and extends behind open
desktop navigation menus. Transparent-header settings still apply.

The mobile hamburger drawer and its submenu panels use the same image and strength
settings. The artwork covers the full drawer height, including when the viewport
height changes. There are no separate mobile image settings to maintain. Images
crop to cover the narrower panel; they are not stretched.

In **Announcement bar**, keep **Use header background image** on to continue the
artwork through that bar. Turn it off to use the bar's own background color.
The announcement text and styling remain editable in its existing blocks.

The homepage hero and Featured products slider use their own existing settings.

`docs/header-watercolor-source.png` (2172 × 724). The deployed image is
`assets/acla-header-watercolor.webp` (127,346 bytes), encoded at the same dimensions
for a smaller download. No new app or script is required.
